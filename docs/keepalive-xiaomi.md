# 小米 / Redmi（MIUI · 澎湃OS）保活设置指南

无障碍类应用最怕被系统杀后台。按下面四步设置一次，轻跳就能长期驻留。

## 1. 允许自启动

> 设置 → 应用设置 → 应用管理 → 轻跳 → 自启动 → 开启

## 2. 省电策略改为无限制

> 设置 → 应用设置 → 应用管理 → 轻跳 → 省电策略 → 无限制

澎湃OS 新版入口可能叫：`设置 → 省电与电池 → 更多电池功能 → 应用智能省电`，找到轻跳选「无限制」。

## 3. 最近任务卡片加锁

打开最近任务（上滑停顿），找到轻跳卡片，**长按卡片 → 锁定**（出现小锁图标）。这样一键清理不会杀掉它。

## 4. 重启后重新开启无障碍（常见坑）

MIUI/澎湃OS 重启或更新后可能自动关闭无障碍开关。表现是：广告不再被跳过。
处理方法任选其一：

- 重新打开：`设置 → 更多设置 → 无障碍 → 已下载的应用 → 轻跳 · 自动跳过服务 → 开启`
- 建议同时开启**无障碍快捷方式**（同页面底部），之后从屏幕边缘即可快速开关服务。

## 验证服务是否活着

打开轻跳 App，首页显示「● 无障碍服务运行中」即正常；显示「未开启」就按第 4 步重新开启。

## 仍然被杀？

1. 关闭「手机管家 → 应用智能省电」里对轻跳的一切限制；
2. 在手机管家里给轻跳「允许后台弹出界面」；
3. 不要使用第三方"一键加速"类应用。
